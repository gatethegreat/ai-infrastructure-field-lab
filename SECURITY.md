# Security policy

## Supported version

Only the current default branch is maintained. This repository is a synthetic
research lab, not production software, a hosted service, or a production-
readiness certification.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form from the repository Security
tab. Do not open a public issue for a suspected credential, privacy exposure,
unsafe workflow, or dependency vulnerability.

Include the affected path, impact, safe reproduction steps, and whether the
report involves content already present in Git history. Do not include real
credentials, client data, or production records in a report.

There is no guaranteed response or remediation SLA. Reports are evaluated in
the context of a non-production research repository.
